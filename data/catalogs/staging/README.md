# Staging de catálogo

Este diretório contém apenas metadados e relatórios distribuíveis no pacote auditado.

Snapshots brutos de provedores externos foram intencionalmente excluídos do ZIP de distribuição porque a auditoria de 14/11/2026 não comprovou uma cadeia de autorização suficiente para redistribuí-los. Para reproduzir uma importação, obtenha o arquivo diretamente da fonte sob licença/autorizações compatíveis, registre o checksum no manifesto e execute o importador offline.

Não trate os manifestos como autorização de uso dos dados referenciados.
