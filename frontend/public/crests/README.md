# Escudos locais

`brasileirao-clubs-reference.png` é a prancha local de escudos da tela de referência fornecida para este projeto. O componente `ClubCrest` usa somente essa cópia local, sem requisições externas, e preserva a proporção de cada marca.

Clubes cobertos: Athletico-PR, Atlético-MG, Bahia, Botafogo, Chapecoense, Corinthians, Coritiba, Cruzeiro, Flamengo, Fluminense, Grêmio, Internacional, Mirassol, Palmeiras, Red Bull Bragantino, Remo, Santos, São Paulo, Vasco e Vitória.

Auditoria beta: a célula rotulada RBB na prancha fornecida mostra uma marca de outro clube. Ela não é usada pelo componente. Bragantino recebe uma identidade provisória claramente rotulada até existir um escudo correto autorizado; os demais recursos fornecidos são preservados. Nenhuma marca externa foi baixada.
